# [76. z最小覆盖子串](https://leetcode.cn/problems/minimum-window-substring)

## 思路

扩张窗口（右指针右移）：

1. 遍历 s 的每个字符，把字符加入窗口；
2. 如果该字符是 t 所需的（charMap[c] > 0），则 count 减 1；
3. 无论是否是 t 的字符，都把 charMap[c] 减 1（非 t 字符会变成负数，标记为 “冗余”）。

收缩窗口（左指针右移）：

1. 当 count = 0 时，说明窗口已包含 t 的所有字符，此时尝试缩小窗口找最小值；
2. 移出左指针字符，charMap[c] 加 1；
3. 如果加 1 后 charMap[c] > 0，说明该字符是 t 必需的且窗口内已不足，count 加 1，收缩停止。

## 解法

### [变长]滑动窗口

```java
class Solution {
    public String minWindow(String s, String t) {
        // 1. 定义长度为128的数组（覆盖所有ASCII字符），统计t中各字符的需求数量
        int[] charMap = new int[128];
        // 2. 初始化charMap：charMap[c] 表示“还需要多少个字符c才能覆盖t”
        for (char c : t.toCharArray()) {
            charMap[c]++;
        }

        // 3. 滑动窗口的左右指针
        int left = 0, right = 0;
        // 4. count：还需要覆盖的字符总数（初始为t的长度，每找到一个t的字符就减1）
        int count = t.length();
        // 5. 记录最小窗口的起始位置和长度（初始长度设为最大值，方便后续比较）
        int minStart = 0, minLen = Integer.MAX_VALUE;

        // 6. 右指针扩张窗口，遍历整个s
        while (right < s.length()) {
            // 7. 取出当前右指针的字符
            char rightChar = s.charAt(right);
            
            // 8. 如果当前字符是t需要的（charMap[rightChar] > 0），则count减1
            if (charMap[rightChar] > 0) {
                count--;
            }
            // 9. 无论是否是t的字符，都将charMap对应值减1（非t字符会变成负数）
            charMap[rightChar]--;
            // 10. 右指针右移，扩大窗口
            right++;

            // 11. 核心：当count=0时，说明当前窗口已包含t的所有字符，开始收缩左指针找最小窗口
            while (count == 0) {
                // 12. 更新最小窗口：如果当前窗口长度更小，记录起始位置和长度
                if (right - left < minLen) {
                    minLen = right - left;
                    minStart = left;
                }

                // 13. 取出当前左指针的字符
                char leftChar = s.charAt(left);
                // 14. 移出左指针字符，charMap对应值加1
                charMap[leftChar]++;
                // 15. 如果加1后该值>0，说明这个字符是t需要的，且窗口内该字符数量不足了，count加1
                if (charMap[leftChar] > 0) {
                    count++;
                }
                // 16. 左指针右移，收缩窗口
                left++;
            }
        }

        // 17. 如果minLen还是最大值，说明没找到符合条件的子串，返回空；否则截取最小窗口
        return minLen == Integer.MAX_VALUE ? "" : s.substring(minStart, minStart + minLen);
    }
}
```
