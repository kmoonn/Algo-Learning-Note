# [438. 找到字符串中所有字母异位词](https://leetcode.cn/problems/find-all-anagrams-in-a-string)

## 思路

> 记忆：统计 p 的频次 → 滑动窗口统计 s 的频次 → 窗口长度达标后对比频次 → 移出左边界字符保持窗口长度。

## 解法

### [定长]滑动窗口

```java
class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        // 1. 定义两个长度为26的数组，分别统计p和s滑动窗口内各小写字母的出现次数（a-z对应0-25）
        int[] cntP = new int[26];
        int[] cntS = new int[26];

        // 2. 初始化结果列表，存储符合条件的起始索引
        List<Integer> res = new ArrayList<>();

        // 3. 统计字符串p中每个字符的出现次数
        for (char c : p.toCharArray()) {
            cntP[c - 'a']++; // 例如 'a'-'a'=0，'b'-'a'=1，以此类推
        }

        // 4. 滑动窗口的右边界遍历s的每个字符
        for (int right = 0; right < s.length(); right++) {
            // 5. 将当前右边界字符加入s的统计数组
            cntS[s.charAt(right) - 'a']++;
            
            // 6. 计算当前窗口的左边界：窗口长度固定为p的长度，left = right - p.length() + 1
            int left = right - p.length() + 1;
            
            // 7. 如果left < 0，说明窗口还没凑够p的长度，跳过后续判断
            if (left < 0)
                continue;

            // 8. 关键：如果两个统计数组完全相等，说明当前窗口是p的异位词，记录left
            if (Arrays.equals(cntS, cntP)) {
                res.add(left);
            }

            // 9. 移出窗口左边界的字符（为下一次右移做准备），保持窗口长度固定
            cntS[s.charAt(left) - 'a']--;
        }

        // 10. 返回结果列表
        return res;
    }
}
```
