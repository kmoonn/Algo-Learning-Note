# [3. 无重复字符的最长子串](https://leetcode.cn/problems/longest-substring-without-repeating-characters)

## 思路

> 记忆：右边界扩张找重复，左边界收缩去重复，全程维护「无重复窗口」并更新最长长度。

## 解法

### 滑动窗口

```java
class Solution {
    public int lengthOfLongestSubstring(String S) {
        // 1. 将字符串转为字符数组，方便按索引访问单个字符
        char[] s = S.toCharArray();
        // 2. 获取字符串长度，作为循环边界
        int n = s.length;
        // 3. 初始化结果变量，存储最长子串长度，初始为0（空字符串的情况）
        int ans = 0;

        // 4. 滑动窗口的左边界，初始为0
        int left = 0;
        // 5. 用数组记录每个ASCII字符的出现次数（ASCII码范围0-127，所以数组长度设为128）
        int[] cnt = new int[128];
        
        // 6. 滑动窗口的右边界，从0开始遍历整个字符串（相当于不断扩大窗口右边界）
        for (int right = 0; right < n; right++) {
            // 7. 获取当前右边界的字符
            char c = s[right];
            // 8. 该字符的计数+1
            cnt[c]++;
            
            // 9. 关键：如果当前字符计数>1（说明窗口内有重复），收缩左边界直到无重复
            while (cnt[c] > 1) {
                // 10. 左边界字符的计数-1（移出窗口）
                cnt[s[left]]--;
                // 11. 左边界右移（缩小窗口）
                left++;
            }
            
            // 12. 更新最长子串长度：当前窗口长度（right-left+1）和历史最大值比较
            ans = Math.max(ans, right - left + 1);
        }
        
        // 13. 返回结果
        return ans;
    }
}
```

## 优化

用长度为 128 的数组替代哈希表，是因为 ASCII 字符范围固定，效率更高。
