# [22. 括号生成]()

## 思路

定义 dp[i] 表示由 i 对有效括号组成的所有字符串的集合

将 i 对括号拆分为「外层 1 对 + 内部 j 对 + 右侧 (i-1-j) 对」，本质是利用有效括号的「框架特性」，确保所有组合都能被拆解为「外层包裹 + 右侧拼接」的形式；

## 解法

### 动态规划


```java
class Solution {
    public List<String> generateParenthesis(int n) {
        // 1. 初始化dp数组：dp[i]存储i对括号的所有有效组合
        List<List<String>> dp = new ArrayList<>();
        // dp[0]：0对括号 → 空字符串
        dp.add(new ArrayList<>());
        dp.get(0).add("");
        // dp[1]：1对括号 → ["()"]
        dp.add(new ArrayList<>());
        dp.get(1).add("()");

        // 2. 从2对括号开始推导到n对
        for (int i = 2; i <= n; i++) {
            List<String> current = new ArrayList<>();
            // 遍历j：内部包含j对，右侧拼接(i-1-j)对
            for (int j = 0; j < i; j++) {
                // dp[j]：内部的j对括号组合
                List<String> inner = dp.get(j);
                // dp[i-1-j]：右侧的(i-1-j)对括号组合
                List<String> outer = dp.get(i - 1 - j);
                // 拼接所有可能的组合
                for (String s1 : inner) {
                    for (String s2 : outer) {
                        current.add("(" + s1 + ")" + s2);
                    }
                }
            }
            dp.add(current);
        }

        // 3. 返回n对括号的组合
        return dp.get(n);
    }
}
```
