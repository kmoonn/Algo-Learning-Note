## 解法

### 前缀和

```java
class Solution {
    public int subarraySum(int[] nums, int k) {
        // 1. 哈希表：key = 前缀和，value = 该前缀和出现的次数
        Map<Integer, Integer> map = new HashMap<>();
        // 2. 初始化：前缀和为0的情况出现1次（关键！处理从数组开头到当前位置的子数组和为k的情况）
        map.put(0, 1);

        // 3. 当前累计的前缀和（从数组第一个元素到当前元素的和）
        int sum = 0;
        // 4. 结果：统计符合条件的子数组个数
        int ans = 0;

        // 5. 遍历数组中的每个元素
        for (int num : nums) {
            // 6. 累加当前元素，更新前缀和
            sum += num;
            
            // 7. 核心逻辑：如果存在前缀和 = sum - k，说明这两个前缀和之间的子数组和为k
            //    把对应的次数加到结果中
            ans += map.getOrDefault(sum - k, 0);
            
            // 8. 将当前前缀和存入哈希表：如果已存在则次数+1，不存在则设为1
            map.put(sum, map.getOrDefault(sum, 0) + 1);
        }

        // 9. 返回最终统计结果
        return ans;
    }
}
```
