# [239. 滑动窗口最大值](https://leetcode.cn/problems/sliding-window-maximum)

## 思路

> 记忆：维护队列单调递减 → 清理视野外下标 → 窗口形成后记录最大值。

核心三步：
1. 维护单调性：新元素入队前，移除队列尾部所有比它小（或等于）的元素下标 —— 这些元素不可能成为后续窗口的最大值，留着没用。

2. 清理视野外元素：队列头部的下标如果超出当前窗口左边界，直接移除（不在窗口内了）。

3. 记录结果：窗口形成后（左边界 ≥ 0），队列头部就是当前窗口最大值的下标，取值存入结果数组。

队列存储的是下标而非数值，这是实现窗口边界判断和数值获取的关键。

## 解法

### 单调队列

```java
class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        // 1. 结果数组长度 = 数组长度 - 窗口大小 + 1（窗口滑动的次数）
        int[] ans = new int[nums.length - k + 1];
        // 2. 双端队列：存储的是nums的下标，而非数值！目的是维护窗口内的最大值下标
        Deque<Integer> q = new ArrayDeque<>();
        
        // 3. 遍历数组每个元素（窗口右边界i不断右移）
        for (int i = 0; i < nums.length; i++) {
            // 4. 核心1：维护队列的「单调递减」特性
            //    如果队列尾部的下标对应的值 <= 当前值，说明它不可能成为后续窗口的最大值，直接移除
            while( !q.isEmpty() && nums[q.getLast()] <= nums[i]) {
                q.removeLast();
            }
            // 5. 将当前元素的下标加入队列尾部（此时队列内元素对应的值是递减的）
            q.addLast(i); 
            
            // 6. 计算当前窗口的左边界：i - k + 1
            int left = i - k + 1; 
            
            // 7. 核心2：移除「视野外」的下标（队列头部的下标超出窗口左边界，说明不在当前窗口内）
            if (q.getFirst() < left) { 
                q.removeFirst();
            }
            
            // 8. 当窗口左边界 >= 0 时，说明窗口已形成（长度达到k），记录当前窗口最大值
            if (left >= 0) { 
                ans[left] = nums[q.getFirst()]; // 队列头部就是当前窗口最大值的下标
            }
        }
        // 9. 返回结果数组
        return ans;
    }
}
```
